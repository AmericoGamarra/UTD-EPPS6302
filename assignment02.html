2.b Use gtrendsR package to collect data (use gtrendsR01.R program)

## EPPS 6302 Methods of Data Collection and Production
## Google Trends with R

#install.packages("gtrendsR")
library(gtrendsR)
TrumpHarrisElection = gtrends(c("Trump","Harris","election"), onlyInterest = TRUE, geo = "US", gprop = "web", time = "today+5-y", category = 0, ) # last five years
the_df=TrumpHarrisElection$interest_over_time
plot(TrumpHarrisElection)

2.d What are the differences between the two methods?

  • Table schemes are different.
  • For web version, the data comes with 2 rows as header before column names and the data is organized into wide form which displays keywords at columns.
  • For the R version, it comes “ready to use/read”. The data structure seems to be long displaying the statistics in column / keyword. The column contains information related to the statistics.
