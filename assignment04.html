c. Suggest a data plan to acquire web data for research.

Data providers typically make their information available on websites instead of granting direct access to their databases. Since these databases are not openly accessible, researchers often rely on web scraping to gather the required data. For instance, financial statements for many companies can be extracted from Yahoo Finance using such techniques. Because of that the plan should include attempt to use APIs or directly access databases when possible, a second option would be web scraping and utilize specialized libraries like rvest or rSelenium for dynamic pages and for flexible scraping and parsing.
